# КАПСУЛА — сайт Алёны Ашихминой и Екатерины Ерохиной

Промосайт фотографов выпускных альбомов в Луганске и области. Основная версия оформлена как эмоциональная капсула времени, содержит пять актуальных тарифов сезона 2027 и прямые контакты. Проект построен на React, адаптирован для мобильных устройств, пререндерен для поисковых роботов и подготовлен для ISPmanager.

Публичные страницы:

- сайт — `https://альбом-лнр.рф/`;
- условия и реквизиты — `https://альбом-лнр.рф/legal/`;
- политика обработки персональных данных — `https://альбом-лнр.рф/privacy/`.

Старые дизайнерские концепции оставлены только как `noindex`-переходы на главную и не конкурируют с ней в поиске.

## Установка в ISPmanager

Репозиторий должен находиться отдельно от каталога домена. Например, клонируйте его в `/root/alena-ashikhmina-photo`, а не в `/var/www/www-root/data/www/xn----7sbd3bcejew7i.xn--p1ai`.

Первый раз:

```bash
git clone https://github.com/Vladislav-shev/alena-ashikhmina-photo.git
cd alena-ashikhmina-photo
npm run deploy
```

Если папка проекта уже открыта в терминале, нужна только одна команда:

```bash
npm run deploy
```

Она устанавливает готовую сборку `ispmanager-dist` в каталог домена. `npm install`, `apt`, Docker, Caddy, `curl`, `tar` и `rsync` не используются. Нужны только уже установленные Node.js и npm; папка `node_modules` для установки сайта не требуется.

Перед заменой создаётся резервная копия, сохраняется каталог `.well-known`, а после установки восстанавливаются владелец и безопасные права файлов. По умолчанию используются:

- каталог сайта — `/var/www/www-root/data/www/xn----7sbd3bcejew7i.xn--p1ai`;
- резервные копии — `/var/backups/alena-ashikhmina-photo` или `.deploy-backups` внутри проекта, если системный каталог недоступен.

Обработчик PHP можно оставить включённым. После копирования установщик сам проверяет HTTPS, перенаправление, пререндер, `robots.txt`, `sitemap.xml` и правовые страницы. Если ISPmanager показывает заглушку REG.RU, файлы не откатываются: команда выводит точные действия для сертификата и каталога сайта.

## Обновление одной командой

Откройте папку проекта и выполните:

```bash
npm run update
```

Команда сделает безопасный `git pull --ff-only` и сразу установит обновлённую готовую сборку. Хранятся пять последних резервных копий.

Повторная внешняя проверка:

```bash
npm run check:production
```

## SEO и юридическая основа

- `robots.txt`, `sitemap.xml`, canonical, Open Graph и JSON-LD `Organization` входят в готовую сборку;
- главная и правовые страницы содержат готовый HTML без зависимости от JavaScript;
- формы, аналитика, рекламные cookies и онлайн-оплата не подключены;
- неподтверждённые реквизиты собраны в `content/legal-profile.json` и не заменяются догадками;
- вопросы владельцу и шаблоны документов находятся в `docs/legal/`;
- порядок регистрации в Яндекс Вебмастере — `docs/yandex-launch-checklist.md`.
