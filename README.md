# ГЛАВА — сайт Алёны Ашихминой

Промосайт фотографа выпускных альбомов в Луганске. Проект построен на React, адаптирован для мобильных устройств и подготовлен для ISPmanager.

В одной сборке доступны четыре самостоятельные подачи:

- основная версия — `https://альбом-лнр.рф/`;
- «Кино» — `https://альбом-лнр.рф/kino/`;
- «Глянец» — `https://альбом-лнр.рф/glianets/`;
- «Капсула» — `https://альбом-лнр.рф/kapsula/`.

## Установка в ISPmanager одной командой

Команда рассчитана на существующий сайт `альбом-лнр.рф` с каталогом `/var/www/www-root/data/www/xn----7sbd3bcejew7i.xn--p1ai`:

```bash
curl -fsSL https://raw.githubusercontent.com/Vladislav-shev/alena-ashikhmina-photo/main/install-ispmanager.sh | sudo bash
```

Установщик:

- проверит точный каталог сайта;
- сохранит резервную копию прежнего содержимого в `/var/backups/alena-ashikhmina-photo`;
- скачает готовую статическую сборку;
- заменит файлы сайта и сохранит владельца каталога;
- установит сразу все четыре версии и их изображения;
- пропустит `apt update`, если нужные системные утилиты уже установлены;
- не будет устанавливать Docker, Caddy или занимать дополнительные порты.

Обработчик PHP можно оставить включённым. HTTPS и домен продолжает обслуживать ISPmanager.

## Обновление

Для обновления сайта запустите ту же команду повторно. Перед заменой файлов снова будет создана резервная копия.

## Локальная разработка

```bash
npm ci
npm run dev
npm run build:ispmanager
```

## Что нужно заменить перед рекламным запуском

- номер телефона и ссылки на мессенджеры;
- окончательные тарифы;
- получателя формы заявки;
- юридические реквизиты и политику обработки персональных данных.
