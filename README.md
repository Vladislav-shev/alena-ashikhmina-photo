# КАПСУЛА — сайт Алёны Ашихминой и Екатерины Ерохиной

Промосайт фотографов выпускных альбомов в Луганске и области. Основная версия оформлена как эмоциональная капсула времени, содержит пять актуальных тарифов сезона 2027 и прямые контакты. Проект построен на React, адаптирован для мобильных устройств и подготовлен для ISPmanager.

В одной сборке доступны семь самостоятельных подач:

- основная версия — `https://альбом-лнр.рф/`;
- «Кино» — `https://альбом-лнр.рф/kino/`;
- «Глянец» — `https://альбом-лнр.рф/glianets/`;
- «Капсула» — `https://альбом-лнр.рф/kapsula/`;
- «Вспышка» — `https://альбом-лнр.рф/flash/`;
- «2046» — `https://альбом-лнр.рф/2046/`;
- «Музей» — `https://альбом-лнр.рф/museum/`.

## Установка в ISPmanager

Репозиторий должен находиться отдельно от каталога домена. Например, клонируйте его в `/root/alena-ashikhmina-photo`, а не в `/var/www/www-root/data/www/xn----7sbd3bcejew7i.xn--p1ai`.

Первый раз:

```bash
git clone https://github.com/Vladislav-shev/alena-ashikhmina-photo.git
cd alena-ashikhmina-photo
npm run deploy
```

Если папка проекта уже открыта в терминале, нужна только одна команда:

```bash
npm run deploy
```

Она устанавливает готовую сборку `ispmanager-dist` в каталог домена. `npm install`, `apt`, Docker, Caddy, `curl`, `tar` и `rsync` не используются. Нужны только уже установленные Node.js и npm; папка `node_modules` для установки сайта не требуется.

Перед заменой создаётся резервная копия, сохраняется каталог `.well-known`, а после установки восстанавливаются владелец и безопасные права файлов. По умолчанию используются:

- каталог сайта — `/var/www/www-root/data/www/xn----7sbd3bcejew7i.xn--p1ai`;
- резервные копии — `/var/backups/alena-ashikhmina-photo` или `.deploy-backups` внутри проекта, если системный каталог недоступен.

Обработчик PHP можно оставить включённым. HTTPS и домен продолжает обслуживать ISPmanager.

## Обновление одной командой

Откройте папку проекта и выполните:

```bash
npm run update
```

Команда сделает безопасный `git pull --ff-only` и сразу установит обновлённую готовую сборку. Хранятся пять последних резервных копий.
