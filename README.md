# ГЛАВА — сайт Алёны Ашихминой

Промосайт фотографа выпускных альбомов в Луганске. Проект построен на React, Next.js и Vinext, адаптирован для мобильных устройств и готов к запуску через Docker.

## Установка одной командой на Ubuntu / Debian

Запустите на чистом сервере:

```bash
curl -fsSL https://raw.githubusercontent.com/Vladislav-shev/alena-ashikhmina-photo/main/install.sh | sudo bash
```

Установщик:

- установит Docker и Docker Compose, если их нет;
- скачает проект в `/opt/alena-ashikhmina-photo`;
- соберёт и запустит приложение;
- подключит Caddy и автоматический HTTPS;
- настроит автоматический перезапуск контейнеров после перезагрузки сервера.

До обновления DNS сайт также доступен по адресу `http://IP_СЕРВЕРА`.

## Подключение домена

Направьте A-запись домена `альбом-лнр.рф` на IP сервера. В проекте уже установлен его технический IDN-адрес:

```env
SITE_ADDRESS=xn----7sbd3bcejew7i.xn--p1ai
```

После изменения домена примените настройку:

```bash
sudo docker compose up -d
```

Caddy автоматически выпустит HTTPS-сертификат.

## Обновление

```bash
cd /opt/alena-ashikhmina-photo && sudo bash update.sh
```

## Локальная разработка

```bash
npm ci
npm run dev
```

## Что нужно заменить перед рекламным запуском

- номер телефона и ссылки на мессенджеры;
- окончательные тарифы;
- получателя формы заявки;
- юридические реквизиты и политику обработки персональных данных.
